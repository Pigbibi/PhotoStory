# 通知与故障处理

PhotoStory 当前提供给所有者使用的通知是站内通知。首页加载时读取保存的发布问题，
页面打开期间定期刷新。项目目前不发送邮件、浏览器推送、短信，也不会把消息转交给
第三方服务。

发布失败只保留固定阶段、时间、HTTP 状态和数字化的服务商错误码。服务商原始响应、
访问令牌、授权码和包含凭据的 URL 不会显示在浏览器中。通知会跳转到发布队列，方便
所有者查看对应项目的当前状态。

- **需要授权处理**：在官方页面完成重新连接或账号验证；只有出现受保护的恢复按钮时才执行恢复。
- **发布需要处理**：先检查保存的失败阶段和准确批准版本。
- **结果不确定**：Instagram 可能已经接受请求。先检查 Instagram 及已记录的容器或媒体 ID，系统不会自动重放。
- **存储警告**：检查保留策略和容量；清理不会删除待审核照片。

发布期间保持网站打开。若浏览器在某一步完成后关闭，使用“继续发布”；服务端会根据
已保存状态继续，不会重建已经完成的容器。遇到账号验证时，只在服务商官方页面完成
验证，回到 PhotoStory 后仅使用页面提供的“验证后恢复”。

不要删除失败或结果不确定的发布记录来强制重试。网站不可用时，应检查部署日志和私有
发布记录；排查过程中不要输出令牌或服务商原始响应。

VPS 维护定时器负责定时扫描、令牌续期、临时文件清理和自动发布推进，必须保持运行。
定时器停止目前不会触发离线通知，需要依靠部署环境自己的服务监控。机器凭据保护的
`GET /internal/health` 是外部监控使用的脱敏只读状态接口。它只返回固定告警类别、
定期任务和作业状态、存储用量、授权到期元数据以及发布问题状态，不返回文件夹、文案、
照片 ID、服务商 URL 或凭据。监控在 `ok=false` 时按类别和时间告警即可；接口不会发布、
续期授权、重试任务或修改状态。需要邮件或聊天告警时，不要把 PhotoStory 密钥或照片数据
发送给监控服务。

启用自动发布前，使用所有者账号确认站内提示可见，确认维护定时器有进程监控，并在非
生产环境验证一次“不确定结果”的处理路径。
