# 定期制作与照片保留

## 照片放在哪里

OneDrive 原图始终留在 OneDrive；PhotoStory 不删除原图。VPS 下载最长边
768 像素的预览，移除 EXIF 后发送给部署者配置的 Codex 服务。运行 Codex
客户端不等于在 VPS 本地运行识图模型。草稿存于 Cloudflare D1；入选预览默认在 D1，也可按[存储教程](storage.zh-CN.md)迁至私有 R2，
需要允许名单内的 GitHub 用户登录才能查看。照片、草稿和凭据不进入开源仓库。

## 制作规则

「连接设置」中的「定期制作与保留规则」可设置独立的来源文件夹、滚动时间范围、
每周或每月、日期和小时。所有时间均按 Asia/Shanghai 计算，短月份自动取月末。
定期制作默认关闭；保存启用后，页面显示下次制作时间。

VPS 的 `photostory-batch.timer` 在上一轮结束后每分钟检查一次。处理器先进行维护、
创建到期任务，再处理一个扫描或 AI 步骤。后台离线或已有任务时会延后；错过多个
周期只补一个任务，不堆积旧周期。创建任务和推进下次时间在同一个数据库事务中，
并发检查不会重复创建任务。失败任务不会自动重试；定期任务失败时还会关闭后续
定期制作，需修复后由你重新启用，避免下个周期重新分析失败批次。

- 默认每次定期制作最多分析 100 张、每批 20 张，可以修改。每次上限范围 1–1000，
  每批仍最多 100；即使某批剩余额度不足，也只分析剩余数量。
- 扫描到的照片数量不等于送给 AI 的数量。相同版本和规则下的已处理照片（包括
  排除的照片）复用 VPS 记录，不再次消耗分析额度。无可靠版本标识的照片不能保证
  跨任务复用；分析计数采用保守上界，可能包含在图片去重阶段跳过的候选。
- 额度用完后任务显示「已达到本次分析上限」，剩余候选留到下次所选范围内检查。
  如果需要补完较旧的照片，请扩大范围或创建手动任务。手动任务不套用定期制作的
  每次总额度，但仍受每批上限和待审核暂停阈值约束。
- 默认待审核达到 20 篇后不再领取后续批次，也不创建新定期任务。正在运行的批次
  会完成，最多可能再产生 3 篇。批准或移入回收站后，积压下降会自动继续。
- 制作默认生成待审草稿；可选严格 AI 自动审核仅用于新任务。两种批准方式都不会触发 Instagram 发布，目前发布仍禁用。详见 README 的审核模式。

## 回收站和清理

待审核和已批准的草稿不设自动到期时间。点击「不采用，移入回收站」后保留
30 天，期间可以恢复到待审核；原先的批准状态不会自动恢复。保存版本校验仍然
有效，旧页面不能覆盖更新后的草稿。

网页清理默认开启，每日 04:00 之后的后台检查清理过期回收站。首次后台检查也会
进行一次清理。预览只有在没有任何草稿引用时才删除，共用图片不会随一篇草稿
误删。编辑时移出的预览也等待至少 30 天才成为清理候选。没有保留记录的历史
孤立预览不会被猜测为过期并删除。

普通临时图片在调用结束时立即清理。可选的 `photostory-cleanup.timer` 每日 04:20
检查超过 24 小时的 PhotoStory 专用临时残留：固定输入文件、上次 AI 输出、
`/var/lib/photostory-ai/call-*` 工作目录。后台正在运行或邮箱锁被占用时跳过；
只删固定目录内的过期文件，不遍历 OneDrive、其他项目或 Codex 登录目录。
关闭网页的定期清理开关会同时阻止这项残留清理，但不改变正常调用结束后的即时清理。

VPS 清理使用独立 root 单元，原因是扫描器和 AI 用户各自拥有不同目录。它只读取
固定系统配置，先从网站确认清理开关；网站不可用时不清理。它不调用 AI，也不执行
网页提供的路径。清理状态由下一次处理器检查上传，只包含时间、固定状态和计数。

扫描进度与去重 SQLite 数据仍保存在私有 `/var/lib/photostory`，不会随临时图片清理。
当前不自动删这些元数据；删除它们可能导致重新分析或无法继续未完成任务。

## 升级已有部署

1. 停止 `photostory-batch.timer`，让正在运行的批次完成，不强杀 AI。
2. 先执行新增的 `photo_gc` 表建表语句（见 `worker/schema.sql`），再部署网站和处理器。
   不删除旧表、任务、草稿或扫描数据库。
3. 安装 `photostory-cleanup.service` 和 `.timer`，校验后重新加载 systemd。
   新单元需要原有 `/etc/photostory/processor.env` 和固定目录，不新增密钥。
4. 启用两个 timer，在网页核对清理状态和定期制作配置；未经配置，定期制作保持关闭。
